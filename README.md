# kaga-me (加賀・芽 / Kaga Me)
> **我獨自升級之現實世界模擬器 (Solo Leveling Real-World Simulator)**  
> 讓參與加賀生活的人，以 RPG 方式與現實世界互動，透過生活實踐升級自我。

---

## 📖 專案願景 (Vision)
**kaga-me** 結合現實日常與虛擬冒險：
- 藉由**讀書、運動、工作、生活實踐**，提升角色能力值與等級。
- 透過**硬體子機與空間物聯網**，達成現實物件與數位世界的雙向互動。
- 離線時，玩家化身為虛擬角色在**加賀世界地圖**中漫步與生活。
- 結合**生活實驗室、工作坊與在地政策/社會參與**，打造真實世界的沉浸式地方創生 RPG。

---

## 🏗️ 系統架構 (Architecture)

### 1. 🖥️ 主機（伺服器 / 虛擬世界觀測站）
* **加賀世界地圖 (World Map)**：
  - 即時反映加賀生活圈各房間與空間狀態。
  - 離線玩家化身為虛擬角色在城鎮中活動（類似《動物森友會》/《朋友收藏》）。
* **專案與行動追蹤**：
  - 整合生活實驗室 (Living Lab)、工作坊與在地專案進度。
* **社會參與儀表板 (Civic Dashboard)**：
  - 借鏡橫濱市財政視覺化儀表板，整合在地組織、政策、公眾議題資訊。
* **遠端互動與戰鬥**：
  - 支援遠端玩家組隊討伐、PK 與裝備/外觀解鎖。

### 2. 📟 小型液晶裝置（隨身子機）
* **微型 LCD 顯示器**（支援 ESP32 / M5Stack 架構）。
* **角色狀態**：顯示姓名、等級與五大維度數值。
* **紙娃娃系統**：點陣像素外觀 / 剪影外觀展示。
* **現實物件互動**：透過 NFC / BLE 感應與計時機制，觸發能力提升與任務回傳。

## 📊 角色數值系統 (Attribute System)

| 數值 | 現實對應行為 | 遊戲內作用與機制 |
| :--- | :--- | :--- |
| **HP (生命)** | 作息規律、睡眠、健康管理 | 充沛時提供經驗加成 (+20%)；過勞進入疲勞狀態需至床鋪休息；戰鬥生存血量 |
| **MP (魔力)** | 專注力 (Willpower)、心流狀態 | 開啟「心流結界」專注計時 Buff；技能施放必備資源 |
| **力量 (STR)** | 重訓、有氧運動、體能活動 | 提升體力勞動任務與戰鬥攻擊力；解鎖戶外與體力專案 |
| **靈巧 (DEX)** | 手作輸出（組模型、繪畫、寫作、料理、木工、Coding） | 製作與鍛造特殊裝備道具；提升作品爆擊率 |
| **智力 (INT)** | 閱讀、研討會、深度討論、學術探索 | 解鎖閱讀心得清單、研究型專案，提供團隊學習光環 |
